# Financial Data Analysis – Kenyan Stock Market

## Project Overview
This project analyzes the financial performance of selected companies listed on the Nairobi Securities Exchange (NSE).

## Companies
- Safaricom PLC
- Kenya Power and Lighting Company (KPLC)
- KenGen

## Objectives
- Analyze stock returns.
- Measure volatility.
- Examine relationships between stock prices and returns.
- Calculate descriptive statistical measures.
- Visualize financial data.
- Develop evidence-based investment insights.

## Tools
- R
- Python
- RStudio
- GitHub

## Statistical Methods
- Descriptive statistics
- Correlation analysis
- Return analysis
- Volatility analysis
- Data visualization
